# 🖐️ HandGestureSystemControl

> Control your computer with hand gestures — no mouse, no keyboard, just your hands.

A real-time, touchless computer interface built with **MediaPipe** for hand landmark detection and **TensorFlow** for gesture classification. Move your cursor, click, scroll, and more — all through natural hand gestures captured by your webcam.

---

## ✨ Features

- 🖱️ **Cursor control** — move the mouse by moving your palm
- 👆 **Left click** — point with your index finger
- ✌️ **Right click** — peace/victory sign
- ✊ **Scroll** — make a fist and move up/down
- 🤙 **Double click** — thumb + pinky gesture
- 👌 **Click & drag** — okay sign to hold and drag
- ⚡ **Real-time inference** — low-latency gesture smoothing with a ring buffer
- 🪟 **Mini preview window** — floating webcam overlay while you work
- 🧩 **Fully configurable** — tune sensitivity, cooldowns, smoothing, and gesture mappings in `config.py`

---

## 🏗️ Architecture

```
Webcam → MediaPipe Hand Landmarker → 63 Features (21 landmarks × x,y,z)
       → TensorFlow Dense Model → Gesture Class → Mouse / System Action
```

The model takes normalized landmark coordinates (relative to the wrist) as input, making it invariant to hand position and scale.

## 🚀 Getting Started

### Prerequisites

- Python **3.10+**
- A working **webcam**
- (Optional) NVIDIA GPU for faster training

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/HandGestureSystemControl.git
cd HandGestureSystemControl
```

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

If any packages are missing after installation, run:

```bash
pip install pandas scikit-learn seaborn
```

### 3. Verify Your Setup

```bash
python test_installation.py
```

This checks all imports, your camera, TensorFlow/GPU availability, MediaPipe, and PyAutoGUI. Fix any reported issues before proceeding.

### 4. Collect Training Data

```bash
python collect_data.py
```

- You'll be prompted to perform each gesture in front of your webcam.
- Press `SPACE` to start/pause capture, `Q` to finish a gesture.
- Default: **300 samples × 6 gestures = 1,800 samples** (configurable in `config.py`).
- Data is saved to `data/landmarks.csv`.

### 5. Train the Model

Open `train_model.ipynb` in Jupyter and run all cells:

```bash
jupyter notebook train_model.ipynb
```

This produces `models/gesture_model.h5` — your trained gesture classifier.

### 6. Run the Controller

```bash
python gesture_controller.py
```

Your webcam will activate and gesture control begins immediately.

## ⚙️ Configuration

All settings are in `config.py`. Key options:

```python
# Gesture recognition
CONFIDENCE_THRESHOLD = 0.85      # Min prediction confidence (0–1)
GESTURE_HISTORY_LENGTH = 6       # Frames in smoothing buffer
GESTURE_STABILITY_REQUIRED = 4   # Frames that must agree to confirm gesture

# Mouse behavior
MOUSE_SMOOTHING = 5              # Higher = smoother but slower cursor
MOVE_SENSITIVITY = 0.3           # Cursor speed multiplier
ACTION_COOLDOWN = 0.8            # Seconds between repeated clicks
SCROLL_AMOUNT = 30               # Scroll distance per gesture

# Data collection & training
SAMPLES_PER_GESTURE = 300
TRAINING_EPOCHS = 100
BATCH_SIZE = 32
```

## 🔧 Troubleshooting

**Camera not detected**
- Make sure no other application is using the webcam.
- Try changing `CAMERA_INDEX = 1` (or `2`) in `config.py`.

**Low gesture accuracy**
- Collect more samples (`SAMPLES_PER_GESTURE = 500` or higher).
- Ensure good, consistent lighting when collecting data.
- Lower `CONFIDENCE_THRESHOLD` slightly (e.g., `0.80`).

**Cursor too jittery / too slow**
- Increase `MOUSE_SMOOTHING` for smoother (but slower) movement.
- Adjust `MOVE_SENSITIVITY` to change speed.

**PyAutoGUI errors on Linux**
- Install `python3-xlib`: `sudo apt install python3-xlib`
- Or use `pip install pyautogui` with a display server running.

## 🤝 Contributing

Contributions are welcome! To add a new gesture:

1. Add the gesture name to `GESTURES` in `config.py`
2. Map it to an action in `GESTURE_ACTIONS`
3. Re-run `collect_data.py` to record samples
4. Retrain via `train_model.ipynb`
